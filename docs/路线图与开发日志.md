## 开发日志

- **v0.2.2(2026-09-11)诊断功能从设置页移到工具栏面板**(用户反馈设置页里点诊断
  永远报"此页面不允许截图":设置页打开即成为活动标签,诊断取「当前页」取到自己)。
  面板弹出时不抢当前页焦点,在目标网页上点面板 →「诊断当前页面」→ JSON 自动进剪贴板。
  诊断若撞上该页正在截图则直接报 BUSY(attach 冲突)。
- **v0.2.1(2026-09-10)飞书文档类虚拟滚动 SPA 拼接修复**(实测反馈:滚动截图飞书
  文档,拼接总是错位/重复)。五个根因一次修完:
  ① 内部滚动容器页 `getLayoutMetrics` 只有 document 高度(≈一屏),真实高度在容器
  `scrollHeight` → METRICS 上报 `scrollerW/scrollerH`,捕获尺寸按容器算;
  ② 捕获前滚动未归零(用户停在页中会缺头部)→ 捕获前 `SCROLL_TO 0`;
  ③ 视口放大后虚拟列表需要时间把占位块换成真实内容 → 新增 `cs/render.stable`
  渲染稳定门控(scrollHeight+DOM 节点数连续两次采样不变),整页/每段/元素捕获前都等它;
  ④ 分段「先滚动后仿真」顺序错误:resize 重排会钳制/漂移 scrollTop,条带错位
  → 改为**先仿真后滚动**,滚动后校验 `applied`,触底钳制时收缩段高防重叠;
  ⑤ 分段范围由一次性测量预切 → 改为**自适应循环**(每轮重测总高,按实际滚动
  位置推进)。另:仿真宽度改用 `innerWidth`(防滚动条消失引发文本重排);元素截图
  改三级路径(视口内 → scrollIntoView+可视区捕获零横幅 → 超高元素仿真条带),
  `rectDoc` 换算到活动滚动容器坐标系;固定高度容器(聊天面板类)明确报错不静默出残图。
- **v0.2.0(2026-09-10)捕获引擎重构:仿真视口机制**(v0.1.1 实测仍只出第一屏——
  证实 `captureBeyondViewport` 即使命名带 clip 也只把超视口区域留白,比例对账防不住
  "尺寸对但内容空白"):
  ① 整页主路径改为 `Emulation.setDeviceMetricsOverride` 把视口放大到整页再拍
  **普通视口截图**(DevTools「Capture full size screenshot」同款机制);
  ② 分段模式重写:每段「仿真视口=段高 + SCROLL_TO 段起点 + 视口截图」;
  ③ 元素截图:视口内元素直接 captureVisibleTab+裁剪(零横幅);超高元素走仿真条带+裁剪;
  ④ `captureBeyondViewport` 降级为最后兜底(旧内核),协议新增 `cs/scroll.to`。
- **v0.1.1(2026-09-10)长图内容缺失修复**(本地实测反馈:整页图只剩一小段、中间内容没拼上):
  ① 整页捕获从「无 clip + captureBeyondViewport」改为**必须带显式 clip**(新版 Chrome
  surface 捕获切换后,无 clip 会把视口外渲染成空白/截断);

  Chrome 渲染有 ~16384px 硬上限,超限截断的图比例必失真,而比例与 clip 按 CSS px
  还是设备 px 的解释无关,一次判定两种歧义;
  ③ 分段模式每段、元素截图同样过比例对账,不合格自动重试/降分辨率。

## 决策记录(ADR 摘要)

- **2026-09-10 引擎选 CDP 而非逐屏拼接**:一次性捕获无拼接错位/sticky 问题;
  代价是调试横幅,自用可接受。拼接引擎不做,分段 clip 只作超大页兜底。
- **可视区/框选不走 debugger**:这两类本可一屏截完,用 captureVisibleTab 完全无横幅。
- **classic SW + importScripts 而非 ESM module SW**:content script 无法 importScripts,
  manifest js 数组顺序是唯一零构建共享常量方案,SW 保持同风格。
- **元素拾取用 contextmenu 现场记录,否决 mouseover 路径回溯**:浏览器原生 hit-test
  即目标,e.target 引用闭包保留,无路径失效问题;isConnected + 30s 新鲜度把竞态
  显式化为错误而非截错区域。
- **图片分块拉取而非 data URL 单发/URL 携带**:几十 MB base64 在消息与 URL 通道都不可靠。
- **分段拼接在 preview 按各段实际解码高度堆叠**:规避非整数 dpr 的数学换算漂移。
- **sticky 用 visibility:hidden 而非 display:none**:sticky 占流空间,后者会让正文
  回流导致长图版式变化;fixed 不在流中,display:none 安全。
- **框选时锁定滚动 + 捕获前隐藏遮罩**:前者保证视口坐标=选区坐标,后者防止把
  暗化遮罩截进图里。

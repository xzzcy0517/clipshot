## 决策记录(ADR 摘要)

- **捕获引擎走 CDP 视口仿真(Emulation)主路径**:一次性全量渲染无逐屏拼接错位;
  `captureBeyondViewport` 经三轮实测证明不可靠(只作旧内核兜底),逐段仿真+preview
  堆叠仅作超大页兜底。调试横幅代价自用可接受。
- **可视区/框选/视口内元素不走 debugger**:captureVisibleTab + canvas 裁剪,完全无横幅。
- **classic SW + importScripts**:content script 无法 importScripts,manifest js 数组
  顺序是唯一零构建共享常量方案,SW 保持同风格。
- **元素拾取用 contextmenu 现场记录,否决 mouseover 路径回溯**:浏览器原生 hit-test 即
  目标,e.target 引用闭包保留;isConnected + 30s 新鲜度把竞态显式化为错误而非截错区域。
- **图片分块拉取(512KB)而非 data URL 单发/URL 携带**:几十 MB base64 在消息与 URL 通道都不可靠。
- **分段拼接在 preview 按各段实际解码高度堆叠**:规避非整数 dpr 的数学换算漂移。
- **sticky 用 visibility:hidden 而非 display:none**:sticky 占流空间,后者让正文回流
  改变长图版式;fixed 不在流中,display:none 安全。
- **框选时锁定滚动 + 捕获前隐藏遮罩**:前者保证视口坐标=选区坐标,后者防止把暗化遮罩截进图里。
- **文档治理:单一权威 + 机械闸门 + 每会话 neat-freak 收尾**:防腐烂不靠自觉,靠
  CI 断言与收尾规程(CLAUDE.md);文档言简意赅、分文件按需加载。
- **超长页三原则(v0.4.0–0.4.5 六连实测蒸馏)**:① 仿真只允许原生 dpr(分数缩放
  大视口必撕裂);② 单边 16000 设备 px 是单张硬顶,超了只能分段,「人看的单张」
  由 preview 分卷合成承担;③ 虚拟列表页探测/滚动/拍摄(含预热)必须同一视口
  配置贯穿全程,逐段清除重建必产生重复缝。物理依据见 CDP 笔记。

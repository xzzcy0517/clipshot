# 新机器部署指南(从零到能在 Cursor 里截图,约 3 分钟)

适合:全新(或重装过的)Mac/Linux 电脑,只有 Cursor、ClipShot 什么都没装。
v0.5.0 起**零配置**:没有 token、没有端口、没有需要常驻的终端窗口。
全程 = 复制粘贴 3 条命令 + 浏览器里点 2 下。

```text
总流程:装 Node → 拿代码 → 跑一键脚本 → 浏览器装扩展 → 勾选启用 → 重启 Cursor 验证
```

## 第 1 步:检查/安装 Node

终端(按 `Cmd+空格` 搜 `terminal`)运行:

```bash
node --version
```

显示 `v18` 及以上 → 去第 2 步。提示 `command not found` → 去
https://nodejs.org/zh-cn 点 **LTS** 下载安装,装完**重开终端**再来一次。

## 第 2 步:拿到代码

```bash
cd ~/Documents                      # 放别处也行,记住路径
git clone git@github.com:xzzcy0517/clipshot.git
cd clipshot
```

> 提示 Permission denied?这台电脑还没配 GitHub 的 SSH 密钥。最省事:
> 浏览器打开仓库页 → 绿色 Code 按钮 → **Download ZIP** → 解压 → `cd` 进解压目录。

## 第 3 步:一键脚本

```bash
bash bridge/setup.sh
```

它自动:检查环境 → 把 ClipShot 注册进 Cursor(`~/.cursor/mcp.json`)→ 自检桥。
结束时会打印一个输出框,写清浏览器里的最后两步。**跑完直接关掉这个终端窗口也没事**
——以后 Cursor 会自动拉起桥,不需要任何常驻进程。

## 第 4 步:浏览器装扩展(唯一手动)

1. Chrome 地址栏进 `chrome://extensions/`;
2. 打开右上角 **「开发者模式」**;
3. 点 **「加载已解压的扩展程序」** → 选第 2 步的 `clipshot` 文件夹
   (setup.sh 输出框里写了完整路径,照着选);
4. 点扩展卡片上的图钉,把图标固定到工具栏(以后一键可达)。

## 第 5 步:勾选启用(唯一设置)

点工具栏 ClipShot 图标 → 面板底部「打开设置页」→「Agent 桥接」→
**只勾一个「启用 Agent 桥接」勾选框**。完。没有要粘贴的东西。

## 第 6 步:重启 Cursor,开用

Cursor **Cmd+Q 完全退出再打开**。然后直接对它说:

> 把当前浏览器页面整页截下来,告诉我内容

首次可先说「用 clipshot_health 查一下桥状态」确认(应答「扩展: 已连接」即通)。
截图落在 `~/clipshot-out/`,Agent 拿路径读图,你双击也能直接看。

## 装到哪了 / 怎么确认 / 怎么卸载

| 东西 | 位置 | 备注 |
|---|---|---|
| Cursor 注册 | `~/.cursor/mcp.json` | `cat` 可见 `clipshot` 条目即已注册;删该条目=卸载(旧版自动备份 `.bak`) |
| 桥进程 | **无常驻** | Cursor 启动时自动拉起、退出回收;看不到进程是正常的 |
| 端口 | 8790–8795 自动 | 冲突自动换,不用管 |
| 截图输出 | `~/clipshot-out/` | 自己清 |
| 扩展 | `chrome://extensions` 移除 | 顺手删掉 mcp.json 条目即彻底干净 |

## 排错速查

| 现象 | 一步解决 |
|---|---|
| Cursor 里没有 clipshot 工具 | 重跑 `bash bridge/setup.sh` 看有无 ✔;Cmd+Q 完全重启 Cursor |
| Agent 说「扩展未连接」 | Chrome 开着吗?设置页勾「启用」了吗?点一下工具栏 ClipShot 图标唤醒,等 30 秒 |
| health 全端口拒接 | 桥没跑:先让 Cursor 完全启动(它会自动拉起),或手动 `node bridge/relay.mjs`(可选,仅调试) |
| 截图报 `BUSY` | 上一张还在截,等 10 秒重试 |
| 截图报 `DEVTOOLS_CONFLICT` | 那个页面开着 F12:关掉再截 |
| 报「页面脚本未就绪」 | 该标签页比扩展更早开:刷新那个网页 |
| 超长文档中段重复/结尾缺 | 扩展版本旧:`git pull` → `chrome://extensions` 点刷新 ⟳ |
| 想重置一切 | 删 `~/.clipshot/relay.json` → 重跑 setup.sh |

## 其它 Agent 怎么接(Codex / 豆包工作 / WorkBuddy / Kimi / Claude)

| 宿主 | 方式 |
|---|---|
| 支持 MCP(Cursor、Claude Code、Codex…) | 跑 `bash bridge/setup.sh`,输出框里有现成配置片段,复制即接 |
| 支持 Agent Skill(Claude Code/Claude) | 把仓库里 `skills/clipshot-screenshot/` 整个目录复制进宿主的 skills 目录即可,**连 MCP 都不用装** |
| 都能跑 shell(Codex CLI、豆包、WorkBuddy…) | 把 `docs/Agent接入指南.md` 第 4 步的「接入提示词」整段发给它(已无 token,更短) |
| 都不行的封闭产品 | 无法接本机桥,属产品限制 |

安全说明:桥只监听 127.0.0.1,网页无法驱动(浏览器 CORS 预检必败);
设置页的「启用」勾选就是总开关,不勾时扩展物理上不会连接任何东西。

# 新机器部署指南(从零到能在 Cursor 里截图,约 5 分钟)

适合:一台全新(或重装过的)Mac/Linux 电脑,只有 Cursor、ClipShot 什么都没装。
全程只需要:复制粘贴 3 条命令 + 浏览器里点 2 下。遇到任何一步不对,直接跳到最后
「排错速查」,每条都有对应解法。

```text
总流程:装 Node → 拿代码 → 跑一键脚本 → 浏览器装扩展 → 粘 token 启用 → 重启 Cursor 验证
```

## 第 1 步:检查/安装 Node

终端(按 `Cmd+空格` 搜 `terminal`)运行:

```bash
node --version
```

显示 `v18` 及以上 → 跳到第 2 步。显示 `command not found` → 去
https://nodejs.org/zh-cn 点 **LTS** 下载安装,装完**重开一个终端窗口**继续。

## 第 2 步:拿到代码

```bash
cd ~/Documents                      # 想放别处就换路径,记住它,后面要用
git clone git@github.com:xzzcy0517/clipshot.git
cd clipshot
```

> `git clone` 提示 Permission denied?说明这台电脑还没配 GitHub 的 SSH 密钥。
> 最省事的替代:浏览器打开 https://github.com/xzzcy0517/clipshot → 绿色 Code
> 按钮 → Download ZIP → 解压,然后 `cd 解压出来的目录`。
> (愿意配密钥的话:`ssh-keygen -t ed25519` 一路回车,把 `cat ~/.ssh/id_ed25519.pub`
> 的内容加到 https://github.com/settings/keys 。)

## 第 3 步:一键设置脚本

```bash
bash bridge/setup.sh
```

它会自动:检查 Node → 把 ClipShot 注册进 Cursor 的 MCP 配置(`~/.cursor/mcp.json`)
→ 自检桥能不能跑通 → 最后打印一个输出框,**里面有一个 token 和两步浏览器操作**。
**这个 token 现在别丢,第 5 步要用。**(它固定存在 `~/.clipshot/relay.json`,忘了随时能看)

脚本跑完后终端会停在一个 `clipshot-mcp …` 日志上,按 `Ctrl+C` 退出即可——
以后不需要手动跑任何东西,Cursor 会自动拉起桥。

## 第 4 步:浏览器装扩展(唯一必须手动的部分)

1. Chrome 地址栏输入 `chrome://extensions/` 回车;
2. 打开右上角 **「开发者模式」** 开关;
3. 点左上角 **「加载已解压的扩展程序」**,选第 2 步那个 `clipshot` 文件夹
   (setup.sh 的输出框里已经把完整路径写好了,照着选);
4. 建议点扩展卡片上的图钉,把 ClipShot 固定到工具栏。

## 第 5 步:把 token 粘进扩展(一次性配对)

1. 点工具栏 ClipShot 图标 → 面板底部「打开设置页」(或扩展详情→扩展程序→选项);
2. 拉到「**Agent 桥接**」:勾选 **启用**;
3. 粘贴第 3 步输出框里那串 token → 它自动保存;
4. 等 30 秒内,「连接状态」应变成 **「● 已连接 relay」**。
   没变?看文末排错表,基本都是这三件事之一:Cursor 没开着 / token 粘贴不完整 / 忘勾启用。

## 第 6 步:重启 Cursor,验证

Cursor 要 **Cmd+Q 完全退出再打开**(不是关窗口)。然后:

1. Cursor 设置(`Cmd+,`)→ 搜 `MCP` → 列表里应有 **clipshot**,状态正常;
2. 在 Chrome 里随便打开一个网页(登录态的也行);
3. 对 Cursor 对话框说:

   > 用 clipshot_health 查一下桥状态

   它应回答「桥正常、扩展已连接」。接着:

   > 用 clipshot 把当前浏览器页面整页截图,给我文件路径

   几十秒后(长页要滚动加载)返回 `~/clipshot-out/` 下的 PNG 路径。双击文件就能看图。
   以后不用点名工具,直接说「截一下我浏览器这个页面」它自己会选。

## MCP 到底装在哪 / 怎么卸载

| 东西 | 位置 | 说明 |
|---|---|---|
| Cursor 的注册配置 | `~/.cursor/mcp.json`(改前旧版备份为 `.bak`) | `cat` 它就能确认装没装上;删掉其中 `clipshot` 条目 = 卸载 |
| Claude Code 注册(若装了) | 由 `claude mcp` 管理 | 卸载:`claude mcp remove clipshot` |
| token / 桥配置 | `~/.clipshot/relay.json` | 删掉 = 重置;`--reset-token` 重新生成 |
| 截图输出 | `~/clipshot-out/` | 自己管理删除 |
| 桥进程 | 没有常驻服务! | Cursor 启动时自动拉起、退出时自动回收,任务管理器里看不到是正常的 |
| 扩展本体 | `chrome://extensions` 删除即卸载 | 顺手把 `~/.cursor/mcp.json` 里的条目删干净 |

## 排错速查

| 现象 | 原因 | 一步解决 |
|---|---|---|
| Cursor 里没有 clipshot 这个 MCP | setup.sh 没跑成功/没重启 Cursor | 重跑 `bash bridge/setup.sh`,看第②步有无 ✔;Cmd+Q 重启 |
| `clipshot_health` 报「扩展: 未连接」 | 第 5 步没完成 | 确认 Chrome 开着 + 设置页已勾启用 + token 完整粘贴;等 30 秒 |
| 连接状态一直「○ 未连接: token 不匹配」 | 粘贴不完整/多了空格 | 去 `~/.clipshot/relay.json` 重抄 `token` 值 |
| 截图报 `DEVTOOLS_CONFLICT` | 那个页面开着 F12 或被 Playwright 占用 | 关掉开发者工具再截 |
| 截图报 `BUSY` | 上一张还在截 | 等 10 秒重试 |
| 报「页面脚本未就绪」 | 该标签页比扩展更早打开 | 刷新那个网页 |
| 超长文档中段有重复行 | 扩展版本过旧 | `cd clipshot && git pull`,到 `chrome://extensions` 点扩展刷新 ⟳,再走第 5 步检查 |
| setup.sh 第②步卡住 | 8790 端口被占 | 跑 `lsof -nP -iTCP:8790 -sTCP:LISTEN` 看占用者:是 `mcp.mjs` = Cursor 的桥在正常干活,不用管;是旧终端里的 `relay.mjs` → 那窗口 Ctrl+C 或 `lsof -ti:8790 \| xargs kill` 后重跑;或 `bash bridge/setup.sh --port 8791`(扩展设置页里端口同步改) |
| 手动跑 `node bridge/relay.mjs` 报 `EADDRINUSE` | **用 Cursor(MCP)方式接入时本来就不需要这一步**,8790 上通常已是 Cursor 自动拉起的桥 | 什么都不用做,直接第 6 步验证;curl 命令照常可用(打的是同一个桥)。详见接入指南排错表「EADDRINUSE」行 |
| 想彻底重置 | — | 删 `~/.clipshot/relay.json` → 重跑 setup.sh → 重新粘 token |

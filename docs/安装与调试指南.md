# 安装与调试指南

## 一、安装(本地电脑)

1. 把代码拉到本地(git clone 或 scp)。
2. Chrome 打开 `chrome://extensions/` → 右上角开启 **开发者模式**。
3. 点 **加载已解压的扩展程序** → 选择仓库根目录(含 `manifest.json` 的那层)。
4. 建议把 ClipShot 图标固定到工具栏。

## 二、使用

| 操作 | 方式 |
|---|---|
| 整页滚动长截图 | `Alt+Shift+F` 或面板按钮 |
| 可视区域截图 | `Alt+Shift+V` |
| 框选区域截图 | `Alt+Shift+S`,拖拽选区,Esc 取消 |
| 截取单个元素 | 元素上右键 → 「ClipShot:截取此元素」 |
| 打开面板 | 工具栏图标或 `Alt+Shift+P` |
| 修改快捷键 | `chrome://extensions/shortcuts` |

截图完成后自动打开预览标签页:可缩放查看、**下载**、**复制到剪贴板**(剪贴板仅支持 PNG,JPEG 结果会自动转码)。

想让 AI Agent(Cursor / 豆包 / Codex 等)自动调用截图:见 **[docs/Agent接入指南.md](Agent接入指南.md)**(三步:启动 relay → 设置页贴 token → curl 验证)。

## 三、必须知道的三件事

1. **调试提示条**:整页/元素截图会短暂出现「ClipShot 正在调试此浏览器」横幅,这是 CDP 截图的正常副作用,截完自动消失。**期间不要点横幅上的「取消」**,否则当次截图中止。可视区/框选截图不出现横幅。
2. **DevTools 冲突**:同一标签页只能有一个调试者。若开着 F12,截图会报「请先关闭开发者工具」——关掉即可。
3. **首次使用旧标签页**:扩展安装前就打开的页面需要刷新一次(报「页面脚本未就绪」同理)。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 长图里 sticky 顶栏重复出现 | 设置里勾选「隐藏固定元素」(默认开) |
| 长图下半部分空白 | 页面是虚拟列表(滚动后销毁 DOM),CDP 无法救回,属已知限制 |
| 提示「此页面不允许截图」 | chrome://、应用商店、PDF 查看器等特权页不可截 |
| 截本地 HTML 文件失败 | 扩展详情页 → 详情 → 开启「允许访问文件网址」 |
| 框选期间页面纹丝不动 | 正常:框选时锁定滚动保证所见即所得 |
| 无限滚动页面 | 会自动在连续增长后停止并提示,已加载部分正常输出 |

## 五、开发工作流(服务器 ↔ 本地)

服务器无浏览器,只做静态校验;行为验证靠本地实测。

```bash
# 服务器上
bash tests/run-all.sh        # 语法 + manifest + 单测,必须全绿再提交
git add -A && git commit -m "..."
git push                     # 配好 remote 后

# 本地电脑上
git pull
# chrome://extensions → ClipShot 卡片上点「刷新」⟳ 图标(改完代码必须手动重载)
```

改了 `manifest.json` 权限或 `background` 后,有时需要把扩展整个移除再重新加载。

## 六、反馈问题时需要提供的信息

1. 复现 URL(或 `tests/fixtures/` 哪个页面)+ 操作步骤;
2. 报错文案(面板/预览页黄条);
3. **诊断 JSON**:停留在出问题的网页上 → 点工具栏 ClipShot 图标 → 面板底部
   「**诊断当前页面(复制排障 JSON)**」→ 成功后直接粘贴发回。
   这是坐标系类疑难(截错位、尺寸不对、飞书类页面拼接问题)最关键的排障信息。
   (会在页面顶部短暂闪一下调试提示条,属正常。注意:要在**出问题的那个网页**
   上点面板里的诊断,而不是在设置页——v0.2.2 起诊断已从设置页移到面板。)

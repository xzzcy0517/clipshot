# 安装与调试指南

## 一、安装(本地电脑)

1. 把代码拉到本地(git clone 或 scp)。
2. Chrome 打开 `chrome://extensions/` → 右上角开启 **开发者模式**。
3. 点 **加载已解压的扩展程序** → 选择仓库根目录(含 `manifest.json` 的那层)。
4. 建议把 ClipShot 图标固定到工具栏。

## 二、使用

| 操作 | 方式 |
|---|---|
| 可视区域截图(**所有页面可用**,含 chrome:// 内部页) | 点工具栏 ClipShot 图标 → 面板第一个按钮 |
| 整页滚动长截图(普通网页) | 面板 → 「整页滚动长截图」(内部页会自动置灰,悬停有原因) |
| 整页截图·手动预热(飞书/Notion 类虚拟滚动超长文档) | 先把页面从头**缓慢滚到底**(滚动条不再变长=加载完成),再点面板「整页截图(手动预热·先滚到底再点我)」;只截已加载部分,未滚完会在提示条告知 |
| 框选区域截图 | 面板 → 「框选区域截图」,拖拽选区,Esc 取消 |
| 截取单个元素 | 元素上右键 → 「ClipShot:截取此元素」 |

(v0.5.0 起不提供快捷键——入口就是面板按钮与右键菜单,够用且零配置。)

截图完成后自动打开预览标签页:**右下角控制面板**统一承载 信息/缩放/画板操作/编辑/复制/下载(剪贴板仅支持 PNG,JPEG 结果会自动转码),无顶栏不遮页面。顶部黄色提示条(捕获路径说明)可点右侧 × 逐条关掉。
缩放(v0.10.1 起)三条通道:**滑杆 5%–400% 无级拖动**、**数字框直接输入百分比**、Ctrl+滚轮平滑微调;−/＋ 按钮为 ×1.1 细调,「适应/100%」一键归位。

**微信式标注(v0.8.0)**:预览页默认干净,操作都收在**右下角控制面板**;不编辑就直接走。
点「编辑」(或按 `E`)顶部升起工具栏:方框/椭圆/箭头/画笔/马赛克/文字/高亮/**形状库**(数字键 1–8);
形状库(v0.10.1)含基本图形、线条(直线/箭头/双箭头/肘形)、流程图(起止框/判断/数据库/文档等)、
UML(类框/生命线/参与者/包/注释)、小图标(云/服务器/浏览器/手机/用户/齿轮),**拖拽放置**,
支持 8 把手缩放、端点拖拽与填充三态(无/淡/实)。
**选项条常驻在工具按钮下方:线宽三档用实心圆示意(细=小圆/粗=大圆,文字档=小/中/大)+ 常用 8 色,即点即改**;
点选已有标注会自动弹出并回显它的颜色/档位,改色改宽**直接作用于该标注**(可撤销)。
画完可**点选再调**:方框/椭圆捏**描边**选中(内部空白可直接套画新标注)、拖 8 个把手改大小(Shift 锁比例)、沿边拖动移位;
箭头拖两端点;文字 **Enter 换行、点空白定稿**(定稿不留框),单击出框可拖动、双击进编辑框重改(清空提交=删除);
选中哪类标注,工具栏就高亮哪个按钮。**马赛克即涂即定,不可再选中拖动**,且只能涂在图片上。
`Shift` 锁正方形/正圆、箭头吸 15°;`Ctrl+Z` 撤销、
`Ctrl+Shift+Z` 重做、`Delete` 删除选中标注(无选中=撤销一步)、「还原」清空全部标注;`Esc/Enter` 完成回预览,
标注保留、可再进「编辑」继续。**原图永不被修改**,复制/下载所见即所得。
v0.10.1 起,编辑态下**点在图片外的画板空白处同样能写字/标注/放形状**(教学批注场景),
导出会把画板上的这部分一起合成出去。

**图片工具(v0.9.0)**:popup「图片工具 → 打开图片编辑」可上传单张/多张本地图片
(≤50MB/张),在新标签页用同款编辑器标注;预览页直接打开(无截图任务)也有上传入口。
预览页即**画板**(v0.10.0):图片是卡片,**按住拖到任意位置**,选中(蓝框)后右下角面板
**等比缩放**(永不拉变形),**下载按画板布局合成一张图**;点空白处蓝框消失。
v0.10.1 起画板可**续传**:「＋ 图片」或 **Ctrl+V 直接粘贴**加图(不刷新页面),
卡片悬停出 **× 可移除**;「🎨 背景」换画布底色(透明棋盘格/白板/常用色/自定义,导出带底色);
「▢ 空白画布」插入一块视口大小的透明画布从零作画。
点「下载」打开**导出弹窗**(v0.9.2 起):左边原图、右边效果实时对比,可**拖框剪裁**、
转格式(原始/PNG/JPEG/WebP)、拖滑杆调压缩质量与缩放,确认按钮直接写明「下载 JPG · 235 KB」这类格式与大小;
右上角「⛶ 全屏」可把弹窗铺满整个页面细看(Esc 逐层退出);
**点任意一侧图可放大**,灯箱里 ←/→ 同位切换原图/导出图细看压缩差异,±按钮 / Ctrl+滚轮无级缩放;
「复制」恒为 PNG。动图按首帧编辑。

## 三、必须知道的三件事

1. **调试提示条**:整页/元素截图会短暂出现「ClipShot 正在调试此浏览器」横幅,这是 CDP 截图的正常副作用,截完自动消失。**期间不要点横幅上的「取消」**,否则当次截图中止。可视区/框选截图不出现横幅。
2. **DevTools 冲突**:同一标签页只能有一个调试者。若开着 F12,截图会报「请先关闭开发者工具」——关掉即可。
3. **首次使用旧标签页**:扩展安装前就打开的页面需要刷新一次(报「页面脚本未就绪」同理)。

## 四、常见问题

| 现象 | 处理 |
|---|---|
| 长图里 sticky 顶栏重复出现 | 设置里勾选「隐藏固定元素」(默认开) |
| 长图下半部分空白 | 页面是虚拟列表(滚动后销毁 DOM),CDP 无法救回,属已知限制 |
| 提示「此页面不允许截图」 | chrome://、应用商店、PDF 查看器等特权页不可截 |
| 截本地 HTML 文件失败 | 扩展详情页 → 详情 → 开启「允许访问文件网址」 |
| 框选期间页面纹丝不动 | 正常:框选时锁定滚动保证所见即所得 |
| 无限滚动页面 | 会自动在连续增长后停止并提示,已加载部分正常输出 |

## 五、开发工作流(服务器 ↔ 本地)

服务器无浏览器,只做静态校验;行为验证靠本地实测。

```bash
# 服务器上
bash tests/run-all.sh        # 语法 + manifest + 单测,必须全绿再提交
git add -A && git commit -m "..."
git push                     # 配好 remote 后

# 本地电脑上
git pull
# chrome://extensions → ClipShot 卡片上点「刷新」⟳ 图标(改完代码必须手动重载)
```

改了 `manifest.json` 权限或 `background` 后,有时需要把扩展整个移除再重新加载。

## 六、反馈问题时需要提供的信息

1. 复现 URL(或 `tests/fixtures/` 哪个页面)+ 操作步骤;
2. 报错文案(面板/预览页黄条);
3. **诊断 JSON**:停留在出问题的网页上 → 点工具栏 ClipShot 图标 → 面板底部
   「**诊断当前页面(复制排障 JSON)**」→ 成功后直接粘贴发回。
   这是坐标系类疑难(截错位、尺寸不对、飞书类页面拼接问题)最关键的排障信息。
   (会在页面顶部短暂闪一下调试提示条,属正常。注意:要在**出问题的那个网页**
   上点面板里的诊断,而不是在设置页——v0.2.2 起诊断已从设置页移到面板。)

# P014 画板教学化增强与形状库

| 状态 | 已实现(用户逐条口述需求,直接批准) |
|---|---|
| 版本 | v0.10.1(commit 6596d33) |
| 依据 | 用户 2026-09-20 实测反馈清单 |

## 需求(用户原话归纳)

1. 缩放每一步 10% 太粗,要能自己调节、更细。
2. 编辑时图片选中的蓝框,点空白处要消失。
3. 画布上可继续上传图片 / Ctrl+V 直接粘贴,继续排版。
4. 编辑工具(写字/标注)在**非图片区域**也能用(教学场景),导出要带上这部分。
5. 画布背景可调:透明 / 白板 / 常用色 / 自定义色。
6. 可新建空白画布,从零自己创作图片。
7. 画板模式=绘图板:常用形状、流程图、系统架构图、UML 时序图、小图标;
   交互符合用户习惯、美观。

## 决策

- **D1 缩放三通道**:滑杆(5%–400% 无级)+ 数字输入(精确%) + 滚轮改平滑
  指数步进(`exp(-deltaY*0.001)`,触控板逐像素);± 按钮保留作粗调(×1.1)。
- **D2 蓝框即点即消**:预览态点卡片以外区域清除 `img.sel` 蓝框(activeImg 仍作
  导出/缩放兜底目标,只去视觉);编辑态点空白本就清标注选中,维持不变。
- **D3 添加图片不进 SW**:画板内 ＋图片 / Ctrl+V 粘贴直接以 blob 建卡片
  (不走 uploadImages→SW→reload 回路,零延迟、排版不丢)。多图时首图 fit 缩放
  归一为 1(布局量语义)。卡片可 × 移除(含 Edit.unmount)。
- **D4 画板标注层**:`#wrap` 注册为编辑器的特殊目标(isBoard,无 bmp),坐标单位
  = 画板布局 px(原点=wrap 左上,s=1);点在图片上=图片标注(原语义),点在
  空白=画板标注。撤销/重做跨目标按操作序号(seq)选最新者。马赛克仍只限图片
  (无背景像素可采样,提示之)。导出:`composeBoard` 在卡片之后以 dpr 比例重绘
  画板标注层;导出 bbox = 卡片 ∪ 画板标注(原点可为负,translate 对齐)。
- **D5 背景**:`boardBg` ∈ transparent | 任意色(localStorage 记忆);透明时 wrap
  显棋盘格;导出合成时非透明则先垫底色。单卡+透明+无画板标注仍走原 blob 直通
  (零回归)。
- **D6 空白画布**:生成视口大小 ×dpr 的透明 PNG 作为普通卡片插入(非破坏式,
  与现有内容共存),缩放/拖动/标注/导出全复用现有机制。
- **D7 形状库**:新工具「形状」(快捷键 8),点开后为分类网格选择器(迷你画布
  图标即代码所画):基本(矩形/圆角/椭圆/菱形/三角/星/五边形/六边形)、线条
  (直线/箭头/双箭头/肘形箭头)、流程图(起止框/平行四边形/圆柱/文档/预定义)、
  UML(类框/生命线/参与者/包/注释)、图标(云/服务器/浏览器/手机/用户/齿轮)。
  拖拽放置;bbox 类复用 8 把手缩放,线条类复用端点拖拽;填充三态(无/淡/实)。
- **D8 导出修复(顺带)**:编辑态导出曾把选中虚线框画进 PNG;导出视图加
  `export` 标志抑制选中态绘制。

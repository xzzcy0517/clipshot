## 1. 用户实测反馈(原话要点)

1. 编辑图片时点「更多」(▾ 下载选项),转换格式和缩放看不懂怎么操作;
2. 这种高级操作应该**弹出弹窗**在里面操作;
3. 压缩应该有**可拖动的进度条**,**左边原图、右边对比图**;
4. 点下载时**不知道下载的是什么格式**,操作不明显。

## 2. 方案(用户拍板方向即此稿)

点「下载」(预览态动作栏 / 编辑态工具栏 / 分卷分段条目)一律打开**「导出图片」模态弹窗**:

- **左右对比**:左栏原图(含标注合成结果,尺寸·格式·大小),右栏按当前选项
  **实时重编码**预览(防抖 200ms,显示输出尺寸·格式·真实编码大小);
- **控件**:格式下拉(原始/PNG/JPEG/WebP,各带一句人话说明)、
  压缩质量滑杆(10–100,仅 JPEG/WebP 显示)、缩放滑杆(10–100% 步进 5,回显目标像素);
- **主按钮文案即答案**:「下载 JPG · 235 KB」——格式与大小一目了然;
  底部附体积变化摘要(如 `2.1 MB → 235 KB(减小 89%)`);
- Esc / 点遮罩 / × 关闭,Enter 确认;弹窗打开期间屏蔽编辑器快捷键
  (dialog keydown stopPropagation + edit.js `modalOpen` 守卫双保险);
- 选项在页面会话内记忆上次值;编码超 32767 画布上限时右栏报错并禁用主按钮。

## 4. 验收(用户实测)

1. 任意图点「下载」出弹窗,左原图右效果,拖质量/缩放滑杆右图与大小实时变;
2. 主按钮始终写明「下载 {PNG/JPG/WEBP} · {大小}」;JPEG q70 体积显著小于 PNG;
3. Esc/遮罩/× 关闭;编辑态下开弹窗,Esc 只关弹窗不退出编辑;
4. 超长图(近 32767px)缩放 100% 转码时报错提示且不可点下载,降缩放后恢复;
5. 复制链路不变(恒 PNG);无标注默认「原始·100%」= 原 blob 直通,零回归。

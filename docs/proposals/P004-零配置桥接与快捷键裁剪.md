## 1. 关键事实(决定方案走向)

1. **Cursor 不支持 Agent Skill**,工具扩展只认 MCP → MCP 通路(`bridge/mcp.mjs`)
   必须保留,它才是 Cursor 的一键通道;`--install` 已做到一条命令。
2. Skill 是给 Claude Code / Claude / 未来兼容宿主用的「说明书+脚本」形态,
   底层仍是调本仓库的 HTTP 桥——**skill 不是新能力,是同一座桥的另一块门面**。
3. 因此:skill **做增量**(30 分钟成本),不替代 MCP。

## 2. 去 token 的安全账(诚实版)

token 现状防两类人:本机其它进程、浏览器里的恶意网页。

- **本机恶意进程**:能读 `~/.clipshot/relay.json` 就能拿到 token——token 本来
  就防不住它;防住了也没意义(能读你文件的进程不需要截图)。→ 删 token 无损失。
- **恶意网页**(真正的风险面):网页对 `http://127.0.0.1:8790` 发 POST 会被
  Chrome 拦,只要 relay 坚持三条:①只绑 127.0.0.1;②POST 强制
  `Content-Type: application/json`(非简单请求 → 触发 CORS 预检);③relay
  **永不返回 CORS 头**(预检必败,请求发不出去)。GET 面只有 health/tabs,
  响应无 CORS 头则网页读不到内容。→ 用协议规则替代人肉密钥,防护不降反稳。
- 结论:**删 token,零复制粘贴**;上面三条写进 relay 实现 + 测试锁死。

## 3. 端口零配置(去「设置页改端口」)

- relay/mcp:按 8790→8795 顺序找空闲端口(占用即下一个),选定后写入
  `~/.clipshot/relay.json`(仅供人看/排错,不再是配置项)。
- 扩展 bridge.js:同样轮询 8790→8795 建 WS(每次心跳周期只试一个,30s 内必连上)。
- 结果:两边都不需要用户填端口。

## 4. 快捷键裁剪

- 删:`manifest.commands`(四个全删,含打开面板的 Alt+Shift+P——点工具栏图标即可)、
  sw 的 `onCommand` 路由、popup 按钮上的 `<span class=kbd>`、options「快捷键」表格、
  接入/安装文档中所有快捷键表述、manifest 测试的 commands 断言(反向断言不存在)。
- 留:popup 三个按钮、右键菜单截元素、面板本身。

## 5. Skill 包(增量)

- 新增 `skills/clipshot-screenshot/SKILL.md`(可移植 Agent Skill 规范):
  name/description + 指令正文——探测端口(health)、curl 三种截图(含
  paths/parts 语义)、排错表、`~/clipshot-out` 说明。**不含 token**(§2 后不需要)。
- **不做自动分发(用户拍板,§8.3)**:skill 只随仓库维护,支持 skill 的宿主
  自行复制该目录使用。
- Cursor 用户不看这一节也不影响任何事。

## 6. 用户视角的最终流程(目标态)

**浏览器手动截**:装扩展 → 点图标/右键菜单。完。无快捷键也无所谓。
**Cursor 接入**(新机器全流程):
```bash
git clone … && cd clipshot && bash bridge/setup.sh   # 唯一一条命令
```
然后浏览器里两处点击:①chrome://extensions 加载扩展;②设置页勾「启用 Agent 桥接」。
——没有 token、没有端口、没有终端常驻。重启 Cursor 即可「把当前页面整页截下来」。

## 7. 改动落点

| 文件 | 动作 |
|---|---|
| `bridge/relay.mjs` | 删 token 鉴权;端口自扫;强制 JSON+无 CORS 头;health 增 `port`;协议 hello 去 token |
| `bridge/mcp.mjs` | 内嵌 relay 先探测后自建(端口自扫);`--install` 输出文案零配置化;skill 不分发(§8.3) |
| `background/bridge.js` | hello 去 token;端口 8790–8795 轮询;`bridgeToken`/`bridgePort` 存储项退役 |
| `options/*` | 桥接区删 token/端口输入框(状态行显示已连端口);删快捷键表格 |
| `popup/*`、`manifest.json`、`background/sw.js` | 删 commands 相关 |
| `skills/clipshot-screenshot/SKILL.md` | 新增 |
| `tests/*` | ws/mcp/manifest 对应用例改;新增「无 CORS 头 + 非 JSON 拒绝」用例 |
| `docs/*` | 新机器部署指南/接入指南/安装指南同步(5 分钟 → 3 分钟) |

版本:**0.5.0**(行为变更+移除功能);协议变更(hello/鉴权)由 relay/扩展同步升级,
旧扩展配新 relay 时 hello 缺 token 字段仍放行(向后兼容,新 relay 不校验)。

## 8. 已确认的决策(2026-09-14 用户拍板)

1. 保留「启用 Agent 桥接」勾选框(默认关)。
2. 快捷键全删(含打开面板的 Alt+Shift+P)。
3. **skill 不做自动分发**:只维护在仓库 `skills/clipshot-screenshot/`,
   用户按宿主(Cursor 走 MCP/Claude 系拷 skill/其余用 curl 提示词)自行取用。
4. 旧 relay.json 的 token 字段忽略,不写迁移。

## 2. 交互规格(对标微信肌肉记忆,零反习惯清单)

**进入编辑**:预览态点「编辑」(或按 `E`)→ 底部中央浮出工具栏,当前光标按工具变化。
**工具栏布局**(单行,左→右):
`▭方框 ◯椭圆 ↗箭头 ✎画笔 ▦马赛克 T文字 ⚡高亮 │ 🎨色块+粗细档 │ ↶撤销 ↷重做 还原 │ 复制 下载 ✔完成`

| 交互 | 规格 |
|---|---|
| 方框/椭圆 | 按下拖动画;按住 **Shift 锁正方形/正圆**;松开成一颗(一次拖拽=一个标注) |
| 箭头 | 起点→终点拖;**Shift 吸附 15°**;默认实心箭头样式同微信 |
| 画笔 | 连续轨迹,压感忽略,线宽=粗细档 |
| 马赛克 | 沿拖拽轨迹刷出像素格条带(格大小固定≈12 CSS px);**矢量存轨迹**,导出时才按原分辨率像素化(撤销/改粗细都不重画) |
| 文字 | 点击落字即打字;工具栏就近出现字号档(14/20/28)+色;失焦或 Enter 提交;此后的文字不可回改(D3,撤销重打) |
| 高亮 | 半透明荧光条,沿拖拽轨迹中线铺宽度可随粗细档(粗/更粗两档默认) |
| 颜色 | 8 色点选(红默认/橙/黄/绿/蓝/紫/黑/白),再点当前色块轮播最近 4 色(不弹面板) |
| 粗细 | 三档(细中粗),就近小下拉,选择即生效 |
| 撤销/重做 | 按钮 + **Ctrl/Cmd+Z / Ctrl/Cmd+Shift+Z**;覆盖全部标注操作(含文字提交、还原=可撤销一步) |
| 键盘 | `1..7` 切工具、Esc 完成编辑、Enter=完成、Delete=撤销一步(同微信习惯子集);输入焦点在文字输入框时快捷键让位 |
| 光标 | 各工具专属十字/文字/I 型;编辑态画布 `cursor` 跟手 |
| 完成 | 点 ✔/Enter/Esc → 预览态(保留标注,右下角按钮变「编辑/复制/下载」,图=带标注呈现) |

**长图适配**(微信没有我们的场景,规则如下):编辑对象=当前展示的那一张图(单张/合成张/分卷列表页里的某一分卷,每卷独立编辑互不干扰);编辑态自动滚到视口位置即画不跳版;缩放沿用预览页现有 zoom,标注随图缩放不错位(坐标全部以图像原始像素为单位存储)。

## 3. 技术架构(为丝滑兜底的三条硬规矩)

1. **原图不可变**:图像只作背景位图;所有标注=矢量对象数组 `[{tool,points,color,width,fontSize…}]`,叠在 canvas 层上。任何时刻可「还原」回原图——**不存在毁图可能**;
2. **渲染**:双层 canvas(背景层按需块状重绘,标注层纯矢量重放);编辑重绘只画标注层,超 30000px 高度时只渲染视口±1 屏,目标 60fps;坐标换算单一函数(图像像素↔屏幕 px,含 zoom),写进 `preview/edit.js` 顶部纯函数区供 node 测试;
3. **导出**:复制/下载时才把标注层按**原始分辨率**一次性合成到离屏 canvas → PNG(剪贴板恒 PNG,与现状一致;JPEG 原图无标注走现状直通不过编码)。

**会话边界**:标注存本标签页内存(闭包),刷新页面丢标注、原图重新从 imagestore 拉(与现状一致);标注不落盘不上传(自用零负担)。

## 6. 验收(人工清单,服务器测不了交互)

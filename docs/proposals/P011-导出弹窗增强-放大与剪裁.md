## 1. 实测反馈与根因

**bug:右栏一直显示「处理中…」**。根因:`.pane-tip` 自定义 `display:flex` 的优先级
高于 UA 样式表 `[hidden]{display:none}`,`tip.hidden = true` 设了也不隐藏——
预览其实已完成,遮罩没消失。修复:补 `#dlmodal .pane-tip[hidden]{display:none}`。

## 2. 新增能力(用户拍板方向即此稿)

- **点击放大(灯箱)**:左右两栏图均可点击放大;灯箱内「原图 / 导出图」按钮与
  ←/→ 键**同位切换**(保持缩放模式与滚动位置比例,方便对比压缩 artifacts);
  点图或按钮切换 适应窗口 / 100% 原大;Esc/点遮罩关闭(捕获相监听,不干扰编辑器)。
- **左栏剪裁**:点「✂ 剪裁」进剪裁态,在左图上**拖框选保留区域,松手即生效**,
  右栏实时重编码;框可拖动移位、框外重拖重画,<8px 误触自动丢弃;
  「清除剪裁」恢复整张;Esc 先退剪裁态再关弹窗;剪裁框在 contain 布局下按
  内容区精确映射(非元素盒),窗口 resize 自动重定位。
- **性能**:源图 `createImageBitmap` 弹窗会话内**只解码一次**(Promise 去重缓存,
  关闭时 `bmp.close()`);编码**互斥不并发**(进行中再触发只记 requeue,完成后补一轮);
  拖动中只更新框与文本,**松手才重编码**;预览防抖 200ms 不变。

## 4. 验收(用户实测)

1. 右栏处理完成后「处理中…」正常消失,图与大小显示;
2. 点左/右图进灯箱,←/→ 同位切换原图与导出图,100% 下可见压缩细节差异;
3. ✂ 剪裁拖框,松手右栏立即更新尺寸与体积;移位/重画/清除均正确;Esc 逐层退出;
4. 快速拖滑杆不卡不连发编码(互斥),松手 200ms 内出结果;超长 PNG 大图流程可用;
5. 默认(不剪裁/原始/100%)仍原 blob 直通,零回归;复制链路不变。

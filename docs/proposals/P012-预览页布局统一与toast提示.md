# P012 · 预览页布局统一:右下角控制面板 + 选中态 + toast 提示

| 状态 | **已实现,待用户实测**(v0.9.5,2026-09-20) |
|---|---|
| 提案日期 | 2026-09-20 |
| 前置 | P009 列表模式逐图按钮 + P010/P011 导出弹窗实测反馈:上传图后右上角 −/＋ 无反应;截图与上传两条链路 UI 不一致;顶栏遮挡「截图预览页本身」;操作提示是顶部文案,不符合习惯 |
| 目标 | 预览态只留右下角一个控制面板(信息/缩放/编辑/复制/下载);多图点选后统一作用于选中图;操作反馈改底部居中 toast |

## 1. 实测反馈与根因

- **上传图片后 −/＋ 没反应**:上传走 `items[]` 列表模式(`initItems`),从不设置主图
  `imgEl`,而缩放 `applyScale()` 只对 `imgEl` 生效 → 全部空转。截图链路走
  `showBlob` 设置主图所以正常。
- **UI 不一致**:截图链路用右下角浮动 `#previewbar`;上传/分卷链路在每图说明行
  自带「编辑/复制/下载」小按钮。用户拍板:统一为右下角。
- **顶栏遮挡**:顶部 header(标题+信息+缩放)会截进「对这个预览 Tab 再截图」的产物。
- **操作提示**:顶部 `#status` 文案不符合习惯,要通用组件式 toast(零依赖自研,
  MV3 不引第三方库)。

## 2. 方案

- **删顶栏**:header 整排移除;信息行、缩放(−/适应/100%/＋/百分比)、
  编辑/复制/下载三行收进右下角 `#previewbar`;面板常驻(加载期只显示信息行,
  `.no-main` 收起按钮行);编辑态仍由 `body.editing` 隐藏。
- **选中模型**:`activeImg` + `Edit.setActive(el)`(edit.js `mainTarget` 改为选中优先、
  回退首张);列表图点击选中(蓝框高亮,编辑态点图是画标注,不抢);信息行显示
  选中图的 文件名 · 尺寸 · 格式 · 大小。
- **缩放按图独立**:`scales` Map 每图一记;列表图初始 `min(1, 适应)`(同旧
  max-width:100% 观感),明确宽度后摘掉 max-width 否则放大无效;Ctrl+滚轮不变。
- **toast**:`#toasts` 底部居中 pill,滑入 2.2s 自动消失,`err` 红色变体;
  复制成功/失败、下载开始、多图提示改走 toast;`#status` 仅留致命加载错误。
- 编辑态工具栏的复制/下载经 `Edit._emit` → 同一出口,自动作用于选中图。

## 4. 验收(用户实测)

1. 上传单/多图后,右下角面板 −/＋/适应/100% 对选中图生效,百分比正确;
2. 截图链路面板位置/行为不变;预览 Tab 自身再截图,画面无顶栏遮挡;
3. 多图点选切换,信息行/缩放/复制/下载都跟随选中图;编辑态工具栏同;
4. 复制/下载后底部居中 toast 自动消失;复制失败红色 toast;
5. 空态(无 job)面板只显示「图片工作台」信息行;门禁全绿。

## 5. 明确不做

不引第三方 UI 库(零依赖纪律);编辑态工具栏位置不变;捕获链路不动。

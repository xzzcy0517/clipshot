# ClipShot 滚动长截图

自用 Chrome 扩展(MV3,零构建零依赖):把整个网页截成一张长图。

- **整页滚动长截图**:自动滚动触发懒加载 → `chrome.debugger` CDP 一次性捕获整页,超大页面自动分段拼接
- **手动预热整页截图**:飞书/Notion 类虚拟滚动超长文档专用——先手动把页面滚到底加载全部内容,再点按钮直接拍(跳过自动滚动,规避中段重复)
- **可视区域截图**:当前一屏,不出现调试横幅
- **框选区域截图**:拖拽选区,所见即所得
- **右击截取元素**:页面任意元素右键 → 「ClipShot:截取此元素」
- **隐藏固定元素**:sticky 顶栏、悬浮客服、飞书类页头/侧栏(滚动容器外的页面元素)可从长图中剔除
- 截图完成后打开**预览页**(即画板):滑杆/数字无级缩放、复制、下载;不想编辑零打扰,
  想标注点「编辑」即得微信同款体验(方框/椭圆/箭头/画笔/马赛克/文字/高亮,
  外加形状库:基本图形/线条/流程图/UML/小图标,撤销还原齐全)
- 预览页也是**图片工作台**:上传或 Ctrl+V 粘贴多张图片自由排版,画布背景可换
  (透明/白板/常用色/自定义),可新建空白画布从零作画,画板任意位置都能写字标注,
  导出按画板布局合成一张图
- 面板、设置页、预览页**跟随系统深浅色**(深色模式下按钮/输入框/边框同步换色)

## 快速上手

日常使用:

1. 打开 `chrome://extensions/`,右上角开启「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本仓库根目录(本地 clone 的目录)
3. 入口:点工具栏图标开面板——「可视区域截图」所有页面可用(含 chrome:// 内部页);整页/元素/框选限普通网页,面板会自动置灰不可用项并悬停说明
4. 截图期间页面顶部会出现「ClipShot 正在调试此浏览器」提示条,**属正常现象,切勿点「取消」**,截完自动消失

详见 [docs/安装与调试指南.md](docs/安装与调试指南.md)。
